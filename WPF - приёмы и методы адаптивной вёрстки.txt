Есть 2 подхода адаптивной вёрстки на WPF:
	1) Выравнивание и границы + отступы;
	2) Контейнеры.

1. Выравнивание. Все визуальные компоненты содержат 4 вида выравнивания (для каждого из них по 4 варианта).
	- HorizontalAlignment (Left, Center, Right, Stretch)
	- VerticalAlignment (Top, Center, Bottom, Stretch)
	- HorizontalContentAlignment
	- VerticalContentAlignment

Границы - свойство у каждого компонента

Margin = "x1, y1, x2, y2" числа - границы в абстрактных пикселях от соседей.
3 варианта:
	1 число - одинаковые границы со всех сторон,
	2 числа - первое слева / справа,
	второе - сверху / снизу
	4 числа - слева, сверху, вправа, снизу (по часовой стрелке)

Padding = "x1, y1, x2, y2" числа - внутренние отступы для Контента.


2. Контейнеры. Contain (содержит) - спец компоненты для управления размещением набора любых других компонентов:
	- StackPanel (стопка), 
	- WrapPanel (авто перенос),
	- DockPanel (стоянка / парковка),
	- Grid(сетка).
Все контейнеры можно комбинировать, вкладывать один в другой и для контейнеров также работают отступы и выравнивание

В системе WPF разработчики создали "Присоединяемые свойства" Attached properties.
	- Когда контейнер Добавляет своим дочерним элементам новые свойства (Присоединяет) с помощью ООП.
DockPanel добавляет компонентам свойство Dock - с выбором 


Сетка позволяет настраивать произвольное кол-во строк и столбцов, 
гибко управлять размерами (абс, относ), 
сетка добавляет дочерним элементам новое свойство Grid.Row="", Grid.Column="".
